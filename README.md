# 🔍 Log Analysis to Ascertain Who is Compromised and How

## 🛡️ Cybersecurity Investigation

This project focuses on analyzing endpoint security, antivirus, quarantine, and web activity logs to identify **which endpoints show evidence of compromise and how the available logs are related to the incident timeline**.

---

## 🎯 Challenge

> **Log Analysis to Ascertain Who is Compromised and How**

### Objectives

- Identify compromised or potentially compromised endpoints.
- Analyze antivirus and quarantine activity.
- Investigate related web activity and blocked connections.
- Correlate events using endpoint IDs and timestamps.
- Identify files and artifacts associated with security events.
- Distinguish confirmed evidence from supporting evidence.
